# JGS Admin Dashboard

Admin dashboard for the **JGS College Website Management System**.

This repository contains only the admin-facing frontend used to manage college operations, users, academic data, fees, reports, and system modules.

## Project Scope

This repo is only for the admin dashboard.

It does not include:

- Public website
- Teacher dashboard
- Student dashboard
- Parent dashboard
- Shared backend API source code
- MongoDB credentials
- Local `.env` files

## Main Features

- Admin login
- Dashboard overview
- Student and staff management
- Bulk student import via CSV
- Fee structure builder
- Timetable drag-and-drop builder
- Exam management
- Reports and analytics center
- Staff payroll module
- Library management
- Hostel management
- Event calendar
- Notices and announcements
- Role-based admin workflow

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Chart.js
- Papa Parse
- jsPDF
